# CURRICULUM

Este repositorio contiene el **sitio personal y académico** de **Guillermo S. Fuentes-Jaque**, publicado en [gfuentes.cl](https://gfuentes.cl). La página reúne información profesional y académica vinculada a geomática, teledetección, estadística, programación, proyectos y publicaciones.

El sitio está construido como una página estática ligera y organizada por secciones. Entre ellas se incluyen la presentación personal, la experiencia, la formación académica, las habilidades, los proyectos y una sección de publicaciones. Dentro de esta última se incorporó una **tesis destacada** con acceso directo a su repositorio institucional, al PDF oficial y a una landing monográfica complementaria.

| Elemento | Descripción |
| --- | --- |
| Sitio publicado | https://gfuentes.cl |
| Dominio configurado | `gfuentes.cl` |
| Enfoque | Perfil académico y profesional |
| Secciones principales | Sobre mí, experiencia, formación, habilidades, proyectos, artículos y contacto |
| Tesis destacada | Estimación espacial de la precipitación mensual en alta resolución en el desierto de Atacama a partir de productos CHIRPS |

## Estructura principal

El repositorio utiliza una organización simple basada en HTML, CSS y JavaScript. El archivo `index.html` define la estructura del documento, `styles/styles.css` concentra la presentación visual y `script/main.js` coordina la carga e inserción del contenido de las distintas secciones.

| Ruta | Función |
| --- | --- |
| `index.html` | Estructura base del sitio |
| `styles/styles.css` | Estilos globales |
| `script/main.js` | Lógica principal de carga y renderizado |
| `script/*.js` | Contenido de secciones específicas |
| `docs/` | Documentos descargables, incluido el CV en PDF |

## Propósito del repositorio

El objetivo de este sitio es ofrecer una presencia web académica y profesional sobria, directa y fácil de consultar. Además de presentar la trayectoria del autor, funciona como punto de entrada hacia publicaciones, proyectos y recursos institucionales asociados a su trabajo.

## Tesis destacada

La sección de publicaciones incluye la tesis:

> *Desarrollo de un método para estimar la distribución espacial de la precipitación mensual en alta resolución en el desierto de Atacama (Chile) a partir de productos CHIRPS*.

Desde el sitio se enlaza a la landing dedicada y a la versión institucional alojada por la Universidad de Chile.
